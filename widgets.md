# Widgets

Scratch list of the profile widgets and the exact URLs behind them. Every one
uses the theme colour `#C2428F` and shades of it on a transparent background, and the
ones that can't adapt on their own are wrapped in a `<picture>` with
`prefers-color-scheme` sources so they follow the reader's GitHub theme.

| Token | Light | Dark |
|---|---|---|
| Title | `A52F72` | `E9A8CC` |
| Accent / line | `C2428F` | `C2428F` |
| Point | `7A2154` | `F7D6EA` |
| Body text | `656D76` | `9198A1` |

Contribution grid levels (empty -> L4):

- Light: `F7D6EA` `E9A8CC` `E9A8CC` `C2428F` `A52F72`
- Dark: `161B22` `301A29` `6B2B50` `C2428F` `E9A8CC`

## In use

- **Nerdy Stats** and **Top Languages** - `github-stats-extended.vercel.app`, transparent `bg_color=00000000`.
- **Contribution Graph** - `github-readme-activity-graph.vercel.app`, area fill on.
- **Contribution Snake** - generated by `.github/workflows/snake.yml` and published to the `output` branch as a light and a dark SVG.
- **Trophies** - `radical` on dark, `flat` on light (the trophy service has fixed themes, so it switches whole themes rather than colours).
- **Visitors** - `count.getloli.com`, already `darkmode=auto`.
